# Guide d'utilisation rapide

**Se connecter** : bouton « Mon espace » en haut du site. Le menu de gauche dépend du rôle.

**Secrétariat — traiter une candidature** : Candidatures → ouvrir le dossier → choisir le statut
(En cours d'examen, Dossier incomplet, Acceptée…) → Enregistrer. Une fois « Acceptée », le bloc
« Confirmer l'inscription » crée le dossier apprenant (matricule CE-AAAA-NNNN) et l'inscription.

**Inscription au guichet** : Apprenants → Nouveau dossier → puis, sur la fiche, « Inscrire à une formation ».

**Comptable / secrétariat — encaisser** : Paiements → choisir l'apprenant et la formation (le reste à payer est affiché),
montant, moyen, référence Orange/Moov Money → « Enregistrer et éditer le reçu » → Imprimer / PDF.
Une erreur se corrige par un remboursement (comptable ou super administrateur), jamais par une modification.

**Responsable pédagogique — formations** : Formations → Nouvelle formation (laisser le tarif vide affiche « Tarif à définir »),
cocher « Publiée » pour l'afficher sur le site. Sur la fiche : ajouter sessions (avec formateur et première classe) et matières.

**Formateur — appel** : Mes classes → la classe → date de la séance → cocher → Enregistrer l'appel.

**Administrateur — contenus du site** : Contenus du site → modifier coordonnées et textes → Enregistrer.
Le badge « provisoire » disparaît dès qu'un champ est modifié.
